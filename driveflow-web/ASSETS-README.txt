ASSETS DE IMAGEM
================

Coloque suas imagens nesta pasta `assets/` com estes nomes exatos:

- avatar.png          Foto/avatar do topo
- icon-help.png       Ícone de ajuda (?) do topo
- icon-menu.png       Ícone do menu (três linhas)
- icon-settings.png   Engrenagem de configurações
- icon-info.png       Ícone de informação do botão Detalhes
- gol-quadrado.png    Imagem principal do Gol, de preferência PNG com fundo transparente
- car-list.png        Miniatura pequena do carro para os botões da lista

Dicas:
- Para ícones, use PNG transparente ou SVG (se usar SVG, troque a extensão no HTML/CSS).
- Para gol-quadrado.png, use uma imagem recortada com fundo transparente, como no Figma.
- O JavaScript aceita `imageUrl` se futuramente sua API retornar esse campo; caso contrário usa `assets/gol-quadrado.png`.
- As imagens não estão incluídas; você deve colocar seus próprios arquivos nesses caminhos.
